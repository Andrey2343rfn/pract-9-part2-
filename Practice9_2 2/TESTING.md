# Контрольний список перед здачею

- [ ] Docker Desktop встановлено та запущено
- [ ] `docker compose up --build -d` виконано без помилок
- [ ] `docker compose ps` показує 6 запущених сервісів
- [ ] У логах Sensor Simulator є публікації датчиків
- [ ] У логах Edge є оброблені записи та повідомлення про аномалії
- [ ] Дані доступні через `/api/summary` та `/api/history`
- [ ] Dashboard відкривається на `http://localhost:8080`
- [ ] Є рухомий графік та шість карток датчиків
- [ ] Команда з Dashboard доходить до Edge
- [ ] Після `docker compose stop cloud-connector` Edge продовжує роботу
- [ ] У локальному SQLite накопичуються непідтверджені записи
- [ ] Після `docker compose start cloud-connector` черга зменшується
- [ ] Знято екран і записано пояснення українською
- [ ] Номер групи додано до звіту та README
